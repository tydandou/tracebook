# 阅读规则

先阅读根规则、健康状态、项目索引和项目状态，再按任务选择相关页面。避免无理由加载完整日志、原始材料、归档或无关项目内容。

默认检索 Current。明确的历史问题或需要旧术语定位的有界补查使用 `--profile audit`；
`--include-history` 仅附带已命中实体的历史，`--as-of` 选择指定日期的版本。
对决定结论的实体用 `--knowledge-id <id> --full-content` 读取完整正文和证据，不能只依赖摘录。
依照已安装 Skill 的检索时机规则，使用新的具体检索键，限制补查和输出预算，核对快照、版本、
生命周期和适用性；证据不足时明确说明缺口，不自动扩大项目范围。
