# Automatic Creation Rules

For a newly discovered project, create only `index.md` and
`project-status.md`. Do not pre-create empty architecture, API, database,
business-rule, source-map, decision, log, or synthesis files.

Create knowledge entities only when a verified conclusion needs them. Each
entity is one schema-v2 authority page keyed by its `knowledge_id`; do not
split a document by line count or route knowledge into aggregate pages. Keep
uncertainty marked as `Pending` and never invent missing facts.
